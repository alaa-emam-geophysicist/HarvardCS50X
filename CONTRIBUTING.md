# Contributing to HarvardCS50X macOS App

First of all, thank you for considering contributing to this project! 🚀

### How to Contribute
1. Fork this repository to your own GitHub account.
2. Clone the forked repository to your local machine.
3. Create a new branch for your changes.
4. Make your changes.
5. Commit your changes with clear, concise messages.
6. Push your changes to your forked repository.
7. Create a pull request to the main repository.

### Code of Conduct
Please be respectful of other contributors. We value a friendly and collaborative environment.

### Issues
If you find a bug or would like to suggest a new feature, feel free to open an issue! You can also check open issues if you'd like to help with ongoing work.

---

Happy coding! 😄
