# HarvardCS50X macOS App 🎓

This is a macOS application built in Swift using SwiftUI. It is designed to help you stay focused and organized while taking the [Harvard CS50x](https://cs50.harvard.edu/x/) course.

---

## ✨ Features

- 🧠 **Greeting Screen**: Shows your name, profile image, age, and course name.
- 📅 **Course Timer**: Countdown based on your selected start date and duration (12 weeks by default).
- 🌐 **Useful URLs Manager**:
  - Add and save CS50-related links.
  - Click to open them in your browser.
  - Drag-and-drop to reorder.
  - Search field to filter links.
  - Confirmation before deleting a link.
  - "Open All" button to launch all saved links at once.
- 💾 **Persistent Data**: Your name, course info, and links are saved in a local JSON file.
- 🎨 **Glass-like Design**: Transparent menu bar-style interface with a modern macOS look.
